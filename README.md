# แบบฟอร์มขึ้นทะเบียนขอใช้สิทธิตามมาตรา 35

ระบบแบบฟอร์มออนไลน์สำหรับการขึ้นทะเบียนขอใช้สิทธิของคนพิการตามมาตรา 35

## รายละเอียดโปรเจกต์

ระบบนี้พัฒนาขึ้นเพื่ออำนวยความสะดวกในการกรอกแบบฟอร์มขึ้นทะเบียนสำหรับคนพิการและผู้ดูแล พร้อมระบบจัดการข้อมูลและการพิมพ์เอกสาร

## ฟีเจอร์หลัก

- แบบฟอร์มกรอกข้อมูลแบบครบถ้วน
- รองรับทั้งคนพิการและผู้ดูแล
- ระบบพิมพ์เอกสารพร้อมจัดรูปแบบ
- บันทึกข้อมูลลง Local Storage
- Responsive Design รองรับทุกอุปกรณ์
- Validation ข้อมูลแบบ Real-time

## เทคโนโลยีที่ใช้

- **HTML5** - โครงสร้างเว็บไซต์
- **CSS3** - การจัดรูปแบบและ styling
- **Bootstrap 5.0.2** - Framework สำหรับ UI
- **JavaScript** - ควบคุมการทำงานของฟอร์ม
- **Google Fonts** - TH Sarabun New

## โครงสร้างโปรเจกต์

```
form-data-v.1.0.0/
│
├── index.html                 # หน้าเว็บหลัก
├── README.md                  # เอกสารนี้
│
├── css/
│   └── custom.css            # Custom styles
│
├── js/
│   └── custom.js             # JavaScript logic
│
├── bootstrap-5.0.2-dist/     # Bootstrap framework
│   ├── css/
│   └── js/
│
├── font/                      # Thai fonts
│   ├── THSarabunNew.ttf
│   └── THSarabunNew-Bold.ttf
│
└── img/                       # รูปภาพและโลโก้
    └── logo.png
```

## การใช้งาน

1. เปิดไฟล์ `index.html` ด้วย Web Browser
2. กรอกข้อมูลในแบบฟอร์มตามส่วนต่างๆ
3. ตรวจสอบความถูกต้องของข้อมูล
4. คลิก "พิมพ์ / บันทึกเป็น PDF" เพื่อพิมพ์หรือบันทึกเป็น PDF
